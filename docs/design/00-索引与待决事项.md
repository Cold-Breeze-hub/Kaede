## 5. 阶段划分（v1，不排总工期）

> 阶段内容见 [`09` 第一版范围与迭代计划](09-第一版范围与迭代计划.md) §4，验收条件同步写在 `01` §9。

| 阶段 | 目标 | 出口条件 |
| --- | --- | --- |
| **S1 骨架与还原** | Electron 壳 + 路由 + SQLite + 全站页面 1:1（走 seed） | 全站可点通、无 404 漏网；原型 CSS 在壳里一致 |
| **S2 内容与源** | Bangumi 刮削 + 规则导入（含 Kazumi 转换）+ 真实搜索详情 | 能搜到真作品、显示真元数据；导入一条社区规则能跑通搜索 |
| **S3 能真的看** | 播放链路 + 跨源拼集 + 失效切换 + miniplayer | 真实源播完一集；杀进程能续；退出后可小窗/纯音频 |
| **S4 能囤** | 下载队列 + 断点续传 + 文件夹识别 + 资源管理 | 整季下载 + 断点续传验证 + 资源可删 |
