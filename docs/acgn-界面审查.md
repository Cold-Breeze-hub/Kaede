## 一、本轮已改（3 项）

### 1. 顶栏搜索框右侧新增「搜索范围」

| 项        | 落地情况                                                     |
| -------- | -------------------------------------------------------- |
| 位置       | 搜索框内右侧，一条分隔线隔开，高度与输入框齐平                                  |
| 选项       | `全部` + 5 个分区（动漫 / 游戏 / 漫画 / 轻小说 / 音乐），右侧标注各自作品数          |
| 交互       | 点按钮弹浮层菜单；点空白处 / Esc 收起；选中项打勾并高亮                          |
| 状态       | `state.searchScope`，默认「全部」；按钮文字、占位文字（`在音乐里搜索…`）同步变化      |
| 结果页（全部）  | 按分区成组，每组标题右侧带条数；分区条此时**一个都不高亮**（结果不属于单一分区）               |
| 结果页（单分区） | 标题写 `音乐 · 搜索「LiSA」`；若别处还有结果，底部给一条「其他分区还有 N 项 · 在全部范围中查看」 |
| 空结果      | 全部范围：提示换关键词；单分区且别处有结果：直接给「在全部范围中搜索」按钮                    |
| 附带       | 搜索态下点分区条＝把范围收到该分区，两处控件指向同一个状态，不会各说各话                     |

> 与旧行为的关键差别：**范围不再绑死在当前分区上**。以前搜「Fate」只能搜到当前分区的 1 部，现在一次能看到动漫/游戏/漫画/轻小说/音乐 5 组共 5 项。

### 2. 典藏卡片封面顶部那条棕色横线

来源是 `.series-card::before` —— 一条 3px 金棕色渐变（`#C9A66B → #9C7E4E`），压在封面最上沿。它和卡内 `.sc-rule` 那条同色系金色细线重复，且位置正好在「封面上方」，远看就是一条不知从哪来的棕线。已删除，装饰线只保留文字区那一条。

### 3. 【P0，顺带修】资源管理页曾整页被一张封面盖住

`.res-cover` 漏写 `position:relative`，而 `.cover-img` 是 `position:absolute;inset:0` —— 42px 的小封面于是去认 `.app` 当包含块，被画成整屏大图，整页内容全被压在下面（就是定稿 §0.13 那条铁律）。已补上并加注释防止再被删掉。

> 顺手把全站 20 个「装封面的盒子」做了一次定位体检：只有 `.res-cover` 一个中招，其余 19 个都正常。
