## 二、待决（需要你选方向，我不擅自改）

### P1 · 结构问题（会改布局，先问）

**10. 作品区工具条在 390 折行，「共 16 部 / 管理」被挤到第二行**
- 现状：`排序 | 全部 | 有更新 | 在看` 一行，`已看完 | 共 16 部 管理` 掉到第二行 —— 看起来像「已看完」和「管理」是一组。
- 与定稿冲突：§2.5 要求工具条一行、管理永远在右上。
- 两个方向：
  - **A（推荐）两行固定**：第一行 `排序 …… 共 N 部 · 管理`，第二行筛选 chips 单独一行。管理态同样两行（`已选 N 项 / 移出 … 完成` + 提示行），**零位移仍然成立**，因为两种状态都是两行。
  - **B 筛选 chips 横滑**：保持一行，chips 区 `overflow-x:auto`，管理固定在右。省高度，但「已看完」在滑出区外，不容易发现。

**11. 下载中心整行被动作区压扁**
- 名称被截成 3 个字（`物语系…`）；`下载中 · 62% / 1.2 MB/s` 折两行；失败行的原因「连接源超时（内置源A / 镜像B 均不可用）」把行撑到 155px（正常行 100px）；同一页行高 100/105/155 三种。
- 根因：`.dl-actions` 放 2–3 个按钮，在 358px 行里占掉 ~150px。
- 建议：窄屏把动作收进「⋯」（主操作留一个：暂停 / 打开 / 重试），或动作整行下移。

**12. 播放器控件在 390 折成 4 行，全屏按钮单独一行**
- 实测：①进度条 + `00:00 / 24:10`｜②`◀ ▶ ▶|` 选集 1080P｜③字幕 简中 / 切源 / 1.0x / 音量｜④⛶ 孤零零靠左。
- 与定稿 §2.11「控件两行」冲突。
- 建议：音量条只在 hover/宽屏出现，窄屏收进一个「⋯」；或把 ①②合并（时间贴着进度条两端，按钮组一行）。

**13. 详情页 4 个按钮折成 3+1，「百科」孤行**
- 主操作 / 加入作品区 / 下载 一行，百科单独一行靠左。
- 建议：把「百科」降级成标题旁的小链接（和系列页「系列主页 ›」同一形态），动作区就固定三个。

### P2 · 一致性（可直接改，但涉及设计口径）

**14. 统计页小数位不统一**：`186.4 小时 / 96 小时 / 62.1 小时 / 38.5 小时 / 29.5 小时` —— 同一列里有的带一位小数有的不带。建议统一一位小数。

**15. 统计页柱状图不是主题色**：本周柱用的是黑灰渐变，全站强调色是青绿（`--sel`）。同一页里「按介质分布」的条是主题色，两个图用了两套色。

**16. 资源管理汇总卡挤**：`最近扫描：今天 09:12` 和「重新扫描」按钮挤在同一行，按钮压着时间。

**17. 磁盘页两处不一致**：①E 盘徽章「已识别」，C/D/NAS 都是「已挂载」——同一状态两种叫法；②每格底部图例 chips 宽度不一，折行后参差（`其它文件 326 GB` 占 2/3 行，`轻小说 2.1 GB` 独占一行）。

**18. 标签广场推荐位三张卡没有封面**：下方所有标签卡都有扇形叠放封面，顶部三张推荐卡是纯文字 + 更矮，第一屏看起来像三块空白。建议沿用同一套 `.tc-stack`。

**19. 典藏卡介质标签折行**：3 个介质（动漫/漫画/轻小说）折成两行，同排卡片的内容底边不齐。建议 chips 限一行 + `+N`。

**20. 空白仍在**：我的页（12 格 + 版本行之后约 45%）、资源管理（未识别区块之后约 35%）。§R41 补过一轮，但这两个页面在 390 下还是空。

### P3 · 工程 / 可寻址性（不影响观感，影响"能不能当网站用"）

**21. 播放器 / 阅读器 / 搜索没有网址**：`#/player/aot`、`#/reader/frieren`、`#/search` 全部落到 404；`#/mine/disk`、`#/mine/resource` 静默渲染成「我的」。刷新、分享、后退都拿不到当前状态。建议给这三者正经路由（`#/player/:id?ep=`、`#/reader/:id?vol=&ch=`、`#/search?q=`）。

**22. 播放器封面卡里同一部作品出现两张小封面**（`.pl-pc-cover` 与集缩略图并排），像是放重了。

## 三、复查结论

- 35 条路由冒烟：`errs: []`，无 `undefined / NaN / [object]`，404 只出现在 `#/nope` 与上面第 21 条的三个地址。
- 详情页 ×5 介质：均只有「分数 + 样本数」，无打分入口。
- 续播按钮：动漫→`继续命运石之门 · 第 5 集`；换一个→消失；切游戏→无；切回动漫→恢复；漫画→`继续电锯人 · 第 15 卷`；音乐→无。
- 横向溢出：除已修的两处外，全站 `document.scrollWidth == clientWidth`。
- 管理态零位移仍成立（工具条原地换内容，未受本轮改动影响）。
